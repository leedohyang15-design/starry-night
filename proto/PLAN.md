# Starry Night — 신규 개발 계획 (2026-08-20)

> 컨셉 문서(starry_night.md)만을 근거로 처음부터 다시 세운 계획.
> 이 폴더의 프로토타입은 기존 빌드와 완전히 독립된 새 코드다.

**한 줄 컨셉**: 별지기가 "별" 카드를 모아, 한 턴에 같은 별자리의 별을 필요 수만큼 내면
성좌가 완성되어 추가 능력이 터지는 StS류 로그라이크 덱빌더.

## 기술 선택

- 단일 HTML + 바닐라 JS (설치 없이 플레이·공유, 수정→새로고침 반복 속도)
- 데이터 주도: 수치·효과는 `STARS`/`CONSTELLATIONS`/`ENCOUNTERS` 테이블에만
- 엔진(Godot 등) 포팅은 웹으로 재미 검증 후 판단

## 코어 규칙 (v0.1 기준선)

- HP 70 · 물질(마나) 3/턴 · 드로우 5장 · 턴 종료 시 손패 버림
- 성좌 판정: **한 턴에** 같은 별자리 별 N장(2~3) → 완성 보너스 (턴당 별자리별 1회)
- 그리스 문자 = 등급 (α 으뜸). 등급이 등장 확률·위력 예산 결정
- 환율표: 물질 1 = 피해 6 = 성막 5 = 뽑기 1장 = 회복 4 = 중독 3 = 취약/약화 1턴
- 등급 예산: α 150% · β 134% · γ 122% · δ 110% · ε 100%

## 확정 결정 (2026-08-20 사용자, v0.2 반영)

1. **성좌 판정 = 한 턴 기준** (전투 누적 아님)
2. **성좌 보너스 = 즉발 + 지속 패시브 병행** — 즉발 6종(쌍둥이·궁수·사자·천칭·카시오페이아·백조, 매 턴 재완성 가능) / 패시브 4종(큰곰 매 턴 성막 3 · 작은곰 매 턴 물질 +1 · 오리온 힘 +2 · 전갈 중독 4+중독 유지, 전투당 1회 "떠오름"). 패시브 턴당 가치 ≈ 즉발의 ~40%
3. **덱 제거 = 기본 카드(시작 덱)만, 상점 지우기 서비스(50 가루)** — 재화 = 별빛 가루(전투 보상 40/60)
4. **조력자 = 하스스톤 영능식 액티브 스킬, 선을 지키는 강도** — 턴당 1회·물질 비용·직접 피해 없음. 갈릴레오 「망원경 관측」(뽑기) · 브라헤 「하늘의 성」(성막) · 프톨레마이오스 「알마게스트」(성좌 판정 +1성). **겹칠수록 강화**: 영능 Lv = 보유 인원(1~3), 전투 승리마다 1인 합류
