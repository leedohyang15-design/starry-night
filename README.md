# Starry Night

> 별지기가 개별 **별** 카드로 덱을 짜고, 같은 별자리의 별을 **한 턴에** 필요한 수만큼 이으면 **성좌**가 완성되는 턴제 로그라이크 덱빌더.

**▶ [지금 플레이](https://leedohyang15-design.github.io/starry-night/)** — 설치 없이 브라우저에서 바로.

적은 어느 별자리에도 속하지 못한 천체들이다 — 행성과 위성, 혜성과 성단, 성운과 블랙홀, 그리고 이름 없는 암흑 물질.

## 이 게임의 규칙은 실제 천문학에서 나온다

장식이 아니라 **수치의 근거**다.

- **카드 등급 = 그 별의 밝기 순위.** 별자리에서 가장 밝은 α가 가장 강한 카드다. 이름도 그대로 부른다 — `작은곰자리 α (북극성)`
- **별자리 그림 = J2000 실측 좌표.** 별자리 중심 입체 투영으로 그렸고, 별선은 Stellarium modern 표준을 따른다. 카드 앞면·성좌판·완성 연출이 **같은 데이터에서 나와 별 인덱스까지 공유한다** — 카드에 강조된 그 별이 연출에서 켜지는 그 별이다
- **미자르-알코르**는 실제로 쌍성이라 한 장으로 성좌 2성을 채운다
- **북극성**은 길잡이라 성좌 완성에 필요한 별 수를 하나 줄인다
- **계절**은 남중 시기다. 제철 별은 +25%, 역계절은 −25%, 주극성은 언제나 무보정
- **조력자는 실존 천문학자 7인** — 갈릴레오·튀코 브라헤·캐럴라인 허셜·케플러·코페르니쿠스·허블·리비트. 능력도 그 사람의 업적에서 나온다(케플러는 궤도가 한 바퀴 돌 때마다, 리비트는 성좌를 완성할 때마다)

## 어떻게 노는가

- 성간 물질 **3/턴** · 드로우 **5** · HP **70**
- 같은 별자리의 별을 **한 턴 안에** 필요한 수만큼 내야 성좌가 완성된다. 턴이 넘어가면 처음부터
- 별자리마다 필요한 별 수가 다르다 (1~3성) · 완성하면 그 별자리 고유의 보너스가 터진다
- **카드는 끌어다 놓아 낸다.** 적이 둘 이상이면 놓은 뒤에 겨눌 적을 고른다
- 키보드로도 된다 — 숫자키로 카드, Space로 턴 종료, Esc로 취소
- 1막 → 2막 → 3막, **45관문**. 막마다 조력자가 한 명씩 합류한다
- 대장간에서 같은 별자리 둘을 **쌍성**으로 벼리면 한 장이 2성을 채운다

## 만들 때 지킨 것

- **단일 HTML 파일** — HTML·CSS·JS 전부 인라인, 빌드 도구 없음, 외부 스크립트는 cdnjs만
- **localStorage 사용 안 함** — 저장이 없다. 한 번 앉으면 그게 한 판이다
- **데이터 주도** — 수치와 효과는 상단 `STARS`/`CONSTELLATIONS`/`ENEMIES` 객체에만. 로직에 하드코딩하지 않는다
- **모든 소리는 웹오디오 합성** — 사운드 파일이 하나도 없다. 별자리마다 완성음이 다르다(사자는 포효, 오리온은 기합, 용은 화염)
- 밸런스를 건드리면 시뮬레이터로 재고 근거를 남긴다

## 개발

새 별자리를 넣거나 그림을 고치려면:

```bash
python gen_const_lines.py            # J2000 좌표 → const_lines.json
python gen_fx_lines.py <빌드.html>    # 카드용·연출용 기하를 함께 주입
python gen_pixel_art.py <빌드.html>   # 적 도트 스프라이트 재생성
```

밸런스를 재려면:

```bash
node dump_sim_data.js <빌드.html> sim_data.json
python sim_battle_v2.py --validate   # 규칙 검산
python sim_bosses.py                 # 조우 시점 덱 기준 보스 승률
```

시뮬레이터의 절대 승률은 **하한선**이다 — 그리디 AI는 사람보다 덱을 못 짠다.
