# Starry Night 카드 제작

별 카드 하나를 만드는 일은 숫자 채우기가 아니라 **별자리라는 아키타입에 조각 하나를 끼우는 일**이다. 아래 순서와 기준을 지키면 카드가 늘어나도 게임이 무너지지 않는다.

## 1. 설계 순서 — 아이덴티티가 먼저다

1. **별자리 아이덴티티부터 확정한다.** 별자리마다 고유 메커니즘 하나(예: 전갈 = 중독, 큰곰 = 방어·가시, 쌍둥이 = 연격, 궁수 = 관통). 다른 별자리와 겹치면 안 된다 — 겹치는 순간 그 별자리를 모을 이유가 사라진다.
2. **성좌 완성 보너스 = 아이덴티티의 정점.** 카드들이 하던 일을 완성 순간 증폭하는 형태로 만든다(중독 별자리면 완성 보너스도 중독). 카드 따로 보너스 따로면 "모아서 잇는" 동기가 죽는다.
3. **그다음에 카드.** 같은 별자리 카드끼리는 셋업→페이오프 시너지가 생기게(StS 아키타입처럼), 별자리 밖 카드와는 효과 조합이 겹치지 않게.

## 2. 환율표 — 모든 수치의 단일 기준

```
물질 1 = 피해 6 = 성막 5 = 뽑기 1장 = 회복 4 = 중독 3 = 취약·약화 1턴
```

- 등급 위력 예산(비용 대비 가치): **α 150% · β 134% · γ 122% · δ 110% · ε 100%**
- 조건부 효과(조건을 맞춰야 발동)는 예산 +20~30%를 허용한다. 페널티(HP 지불 등)는 같은 환율로 환급한다.
- 카드를 낼 때마다 **예산 계산을 한 줄로 명시**한다. 예: `피해 10(1.67) + 중독 4(1.33) = 3.0 / 비용 2 × α 1.5 = 3.0 ✓`
- 감으로 숫자를 매기지 않는다. 예산에서 벗어나면 "왜"를 적는다(시그니처 한 방, 조건부 등).

## 3. 명명 규칙

- 카드 이름 = **"~자리 + 그리스 문자"**, 고유명이 있으면 병기: `작은곰자리 α (북극성)`, `황소자리 θ²`
- **그리스 문자 = 등급**이다. α가 으뜸별(최고 등급). 실존하는 별만 쓴다.
- 문자를 건너뛸 수는 있어도 **순서를 뒤집지는 않는다**(β가 γ보다 낮은 등급이 되면 안 된다).
- 로어 한 줄을 반드시 붙인다 — 실제 천문학 사실에 기반한 짧은 설명("온 하늘에서 가장 밝은 별 — 큰개의 코끝").

## 4. 카드 3원칙

1. **같은 별자리끼리 시너지가 나게** 만든다. 별자리 = 덱빌딩 아키타입.
2. **효과 조합은 게임 전체에서 유일하게.** "효과는 같고 숫자만 다른" 카드 금지. 새 카드를 낼 때 기존 카드 전체와 (효과 종류, 조건) 조합을 대조한다.
3. **"피해 3" 식으로 대충 만들지 않는다.** 민무늬 순수 피해는 시작 덱 급에서만. 나머지는 부가효과·조건·성좌 연계 중 하나는 갖게 한다. 피해를 디버프(취약·약화)로 바꾸면 총 화력이 오히려 오른다는 점을 활용한다.

## 5. 문체 — StS 한국어 정식 문체

- 효과마다 **"~합니다." 짧은 문장으로 분리**: `피해를 12 줍니다. 중독 3을 부여합니다.`
- 상태이상은 **이름 + 숫자 + 조사** 어순: "약화 2를 부여합니다."
- 조건은 후행 문장: "적이 공격할 의도라면 피해가 2배가 됩니다."
- 숫자는 굵게. 카드 속성 키워드는 한 단어 문장(맨 끝 "소멸." 등).

## 6. 산출 형식 — 데이터 주도

수치·효과는 코드 로직이 아니라 데이터 테이블 항목으로만 낸다:

```js
// STARS 항목 예시
antares: { con:'sco', by:'α', name:'안타레스', rank:1, cost:2, type:'공격',
  fx:{ dmg:10, poison:4 },
  lore:'전갈의 심장에서 타오르는 붉은 초거성 — "화성의 라이벌"' },
```

새 효과 종류(fx 키)를 추가하면 효과 실행기·카드 문구 생성기·유일성 검사를 전부 함께 갱신한다.

## 7. 검증 체크리스트 (카드를 낼 때마다)

- [ ] 예산 계산 한 줄 명시 (환율 합계 vs 등급 예산)
- [ ] 효과 조합 전역 유일 (기존 카드와 대조)
- [ ] 별자리 아이덴티티에 부합, 같은 별자리 내 시너지 존재
- [ ] 그리스 문자·등급 순서 유효, 실존 별, 로어 있음
- [ ] 카드 문구가 StS 문체이고 카드 틀을 넘치지 않음
